1️⃣ JS qayerda yoziladi? 1. HTML ichida

2️⃣ O‘zgaruvchilar (variables) JSda 3 xil bor, lekin asosiylari: let va const
let age = 25; const name = "Ali";
let → o‘zgaradi
const → o‘zgarmaydi
❌ Eskisi: var x = 10; // ishlatma
3️⃣ Ma’lumot turlari (Data types)
let number = 10; // number let text = "Hello"; // string let isOnline = true; // boolean let nothing = null; // null let x; // undefined
Tekshirish: typeof number; // "number"
