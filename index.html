Function va Arrow Functionda return tushunchasi

Function — bu ma’lum bir vazifani bajarish uchun yoziladigan kod bo‘lagi. Funksiya ichida yozilgan amallar faqat funksiya chaqirilganda ishlaydi.

Return — funksiya bajarilgandan keyin tashqariga qiymat qaytarish uchun ishlatiladi. Agar return bo‘lmasa, funksiya undefined qaytaradi.

Oddiy function misoli:

function qoshish(a, b) {
return a + b;
}

Bu yerda qoshish nomli funksiya ikkita son qabul qiladi. return a + b orqali ularning yig‘indisini qaytaradi. Natija funksiya chaqirilgan joyga qaytadi.

Arrow function — bu funksiya yozishning qisqa va zamonaviy usuli. U => belgisi bilan yoziladi.

Arrow function misoli:

const qoshish = (a, b) => {
return a + b;
}

Bu arrow function oddiy function bilan bir xil ishlaydi. Farqi — yozilishi qisqaroq va o‘qilishi qulayroq.

Qisqa arrow function — agar funksiya faqat bitta amal bajarsa, return yozmasdan ham qiymat qaytaradi.

const qoshish = (a, b) => a + b;

Bu yerda JavaScript o‘zi avtomatik tarzda return qiladi. Lekin bu faqat bitta qatordan iborat functionlarda ishlaydi.

Xulosa: Oddiy function va arrow function ikkalasi ham bir xil natija beradi. Arrow function yozilishi qisqa, oddiy function esa ko‘proq imkoniyatlarga ega.
